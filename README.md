# 📱 إدارة سوشيال — منصة إدارة السوشيال ميديا بالذكاء الاصطناعي

منصة تتيح لأصحاب الأعمال إنشاء **وكلاء ذكاء اصطناعي** مخصصين، لكل وكيل:
- شخصية وتعليمات خاصة (System Prompt)
- قاعدة معرفة خاصة (ملفات + روابط + نصوص) يُجاب منها عبر **RAG**
- ويدجت دردشة قابل للتضمين في موقع العميل
- لوحة تحكم لمتابعة المحادثات والعملاء والتحليلات

---

## 🧰 التقنيات المستخدمة

| الطبقة | التقنية |
|---|---|
| الواجهة الأمامية | HTML + Tailwind CSS + Vanilla JavaScript (SPA عبر `location.hash`) |
| قاعدة البيانات | Supabase (Postgres + Auth + Storage + Edge Functions + pgvector) |
| محرك الذكاء الاصطناعي | **Gemini 3.1 Flash Lite** |
| نموذج الـ Embeddings | **Gemini text-embedding-004** (768 بُعد) |
| قراءة الملفات في المتصفح | pdf.js + mammoth.js + xlsx.js |
